# Table Tennis Live 🏓

Windows 桌面端乒乓球实时比分客户端，MSN / Microsoft Start 风格。

当前版本：1.9.0，包含现代化浅色/深色界面、平滑滚动、页面过渡、官方比分、得分走势、关注比赛提醒、桌面迷你比分、日历导出、男单/女单世界排名、WTT 与亚运会赛事签表、三大赛分类决赛档案、按需加载的选手资料，以及亚运会乒乓球实时赛程。

Windows x64 用户可从 [GitHub Releases 下载最新安装包](https://github.com/Beyon-cmd/table-tennis-live/releases/latest)，无需安装 Python。源码位于本仓库；请勿将 `release/`、虚拟环境或个人设置提交到 Git。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 构建 Windows 安装包（使用者无需安装 Python）

推荐使用 Windows x64 和 Python 3.12：

```powershell
python -m venv .venv-release
.\.venv-release\Scripts\python.exe -m pip install -r requirements-release.txt
.\build_installer.ps1
```

构建前需安装 Inno Setup，并将编译器放在 `.inno-compiler\ISCC.exe`，
或修改 `build_installer.ps1` 中的编译器路径。
生成 `release\TableTennisLive-1.9.0-Setup-x64.exe`；构建脚本会检查打包后的 Qt 程序能否启动。
打包后程序的数据（收藏、主题设置）保存在 `%LOCALAPPDATA%\TableTennisLive\`。
支持 Windows 10 1809+ / Windows 11 x64。安装包提供快捷方式和卸载功能。
升级时直接运行新版安装包即可；安装目录与 AppId 不变，收藏和主题设置保存在独立的本地数据目录，不会被覆盖。开始菜单和桌面快捷方式显式使用新图标。如果任务栏仍显示旧的固定图标，请先取消固定再重新固定。
本地环境、安装包、缓存和个人设置不纳入源码仓库。

## 已实现

- 顶栏“提醒”可分别开启收藏比赛的开赛提醒（提前 5 分钟或开赛，最多一次）、大比分变化、结束通知；默认全部关闭。通知由系统托盘发出，仅软件运行且系统允许通知时有效；只依据新鲜、已核实的状态变化触发，不补发启动前已结束的比赛。若系统托盘不支持通知，按钮会禁用。
- 顶栏“迷你比分”打开可置顶的小窗，可切换当前直播或已关注的比赛；比分随主程序刷新，关闭主程序后停止。详情页的“加入日历”可导出标准 `.ics`，含本机时间与北京时间；结束时间只是占位，赛程变动须以官方为准。日本 T.League 官网日本时间在载入时换算为本机时间。
- 亚运会单项赛官方 `Result` 总局分更新慢于 `Splits` 已完成局分时，按已结束局数校正上方大比分，并在卡片/详情注明；未结束的一局不参与计算，团体赛不采用此规则。
- 比赛详情新增得分差走势图，横轴是每局累计得分，纵轴是左方减右方的分差。程序运行期间记录实际观察到的局分；实线表示连续采样，虚线表示漏采样。历史赛果只有局末分时只画终值，不推测中间领先与反超。局点与连续得分只在样本足以确认时标记；暂停与赛点预留官方逐分事件/赛制入口，当前来源未提供时不猜测。走势只保存在本次运行的内存中，重启后不会恢复逐分样本。
- 奥运会、世锦赛、世界杯分类具备当期比赛与历届决赛自动切换机制：仅当接入经过核实的官方当期数据源并存在新鲜的进行中/即将开始比赛时显示当期；赛事结束或数据过期则回到历史档案。当前尚未接入这三类的可靠实时接口，因此仍显示已核实的历届决赛，不把旧比赛标为 LIVE。
- 左侧显示各数据源最近成功取数的本机时间；网络异常或官方接口返回缓存时，相关比赛标记“旧数据”，恢复后自动清除。此时间不是官网发布比分的时间。
- 新的简约乒乓球图标用于程序窗口、任务栏、快捷方式和安装包；`assets/icon-source.png` 为带透明通道的原图，运行 `python make_icon.py` 可重新生成包含 16–256 像素七种尺寸的 `assets/icon.ico`。
- “大赛”分为奥运会、世锦赛、世界杯、亚运会四个入口。前三个分类在没有实时签表时分别显示已核实的历届决赛：奥运会 18 场、世锦赛（含团体）40 场、世界杯（含团体及混合团体）43 场；保留总比分、逐局分和已核实的团体赛单场详情。这些条目明确标记为历届决赛，不冒充直播。亚运会保留实时比赛列表并新增官方签表标签，包含男单、女单、男双、女双、混双、男团、女团；沿用 WTT 签表的卡片、拖动、缩放和比分详情，团体赛卡片可按需读取逐场及逐局比分。
- “大赛”默认只显示 2026 爱知·名古屋亚运会乒乓球官方当期赛程，不再用历届决赛充数：在赛期自动读取正在进行、即将开始及最近结束的对阵、总比分和逐局分；团体赛点击详情按需读取单场对阵和每局分。比分依官方成绩系统发布，不估算未公布的数据；网络中断时保留已获取的比分。客户端赛中约每 2 秒检查，官方接口实际发布延迟无法消除。
- WTT 保留原有比赛列表，新增“赛事签表”标签：按赛事、男单/女单/男双/女双/混双、正赛/资格赛切换。赛事级别与原列表一致，不加入支线赛或青少年赛。
- 签表采用官方 CMS `GetBrackets` 数据和 `PreviousUnit` 晋级关系，支持轮空、待定选手、国旗、种子序号与结果；点击卡片查看官方已公布的小比分。未公布的数据不推测。
- 签表展示近期 90 天及未来 60 天赛事，在页面可见时每次请求完成后 30 秒检查一次；失败保留当前签表并标注错误，切换赛事时不显示上一赛事的数据。
- 签表赛事、项目与阶段使用统一的圆角选择器，赛事较多时可搜索；支持＋/－按钮、Ctrl＋滚轮缩放、100% 重置与适应宽度。
- 点击比赛卡、详情中的选手名、世界排名或 WTT 签表中的选手名，可查看资料弹窗；双打先选择具体选手。已确认 WTT ID 时按需读取官网公开的头像、年龄、协会、持拍方式和本年度单打胜率，并可打开对应官网个人页。排名先显示、个人资料和头像随后加载；仅保留少量内存缓存，不在磁盘存储照片或大型选手数据库。官网缺失资料或无法唯一匹配时不猜测。

- Fluent 风格 UI：圆角卡片、轻阴影、大量留白，浅色 / 深色 / 跟随系统三种主题
- 左侧导航：首页 / 实时 / 今日赛程 / 我的关注 / 世界排名，以及大赛、WTT、T.League、TTBL、乒超入口
- 世界排名：官方男单、女单各前 100 名，前三名概览、积分、排名变化及离线缓存。启动及进入页面时检查，每次请求结束后 60 秒再次检查；支持手动刷新。官方排名并非逐场实时积分。
- 数据未变时不重绘排名表格；更新失败保留已有数据，自动重试。关闭窗口后停止排名轮询。
- 比赛列表和详情页采用 180 毫秒平滑滚动，页面切换采用 150 毫秒过渡；触控板保留原生像素滚动。
- WTT 比赛卡片与详情显示官方国家/地区协会旗帜；图片随程序内置
- 首页三个分区：正在进行、即将开始、最近结束
- 比赛卡片：比分、逐局比分、LIVE / FINAL 状态、更新时间、开始倒计时
- 点击卡片进入详情页：WTT 展示大比分与逐局比分；
  T.League / TTBL 展示每场对阵的选手与每局比分（WTT 风格）
- 搜索：可搜索球员、队伍、赛事名，覆盖最近的已结束比赛（历史赛程）
- 常用选手显示中文名（如 张本智和、奥恰洛夫、莫雷加德）；
  详情页保留官方原文名便于对照，未收录的选手保留原名
- 俱乐部显示中文名（如 萨尔布吕肯、杜塞尔多夫、木下东京）
- 真实数据源：WTT / 日本 T.League / 德国 TTBL 均为官方公开数据
- 自动刷新：各数据源独立执行，直播目标轮询间隔约 2 秒；实际延迟受官方更新和网络耗时影响
- 增量更新：内容没有变化的卡片不重绘；网络错误自动退避重试
- 收藏：点击卡片右上角 ☆ / ★，保存到本地 `data/favorites.json`
- 简单搜索：按球员、赛事、队伍名过滤比赛

## 项目结构

```text
table_tennis_live/
├── main.py               # 入口
├── models.py             # Match 数据模型
├── data_sources/
│   ├── base.py           # DataSource 统一接口
│   ├── name_map.py       # 常用选手中英文名对照表
│   ├── wtt.py            # WTT（worldtabletennis.com 官方公开数据）
│   ├── ttbl.py           # 德国 TTBL（ttbl.de 官方公开数据）
│   ├── tleague.py        # 日本 T.League（tleague.jp 官方赛程）
│   └── cttsl.py          # 中国乒超（暂无可公开接口，返回空）
├── services/
│   ├── updater.py        # 后台并发刷新 + 增量比较
│   └── storage.py        # 收藏 / 设置的本地 JSON 存储
├── ui/
│   ├── theme.py          # 浅色 / 深色 / 跟随系统
│   ├── main_window.py    # 主窗口
│   ├── match_card.py     # 比赛卡片
│   ├── match_detail.py   # 比赛详情
│   ├── section_view.py   # 信息流分区
│   └── widgets.py        # 共用组件
└── requirements.txt
```

## 数据源说明（来源可信，不编造数据）

| 赛事 | 来源 | 内容 | 备注 |
|---|---|---|---|
| WTT | worldtabletennis.com 官网公开静态数据 | 赛程、官方结果索引及比赛卡、逐局比分、实时比赛、世界排名 | 缺失数据明确标记，不编造 |
| 德国 TTBL | ttbl.de 官网 Next.js 公开数据接口 | 赛程、队伍比分、每场对阵选手与每局比分 | 队伍制比赛 |
| 日本 T.League | tleague.jp 官网赛程页 + 比赛详情页 | 近一个月赛程、已结束比分、每场对阵选手与每局比分 | 官网无公开实时比分接口，不提供 LIVE |
| 中国乒超 | — | 空 | 暂无可公开访问的官方数据接口；有公开来源后再接入 |

时间说明：WTT 赛程时间按官网数据原样展示（赛事本地时间）；
T.League 为日本当地时间。显示为“—/无比分”的比赛表示官方数据中
没有该比分，程序不会自行猜测。
